# Независимая оценка ответов

Координатор выдаёт одному человеку только r1.csv, а второму — только r2.csv. Не показывайте участникам исходные ответы, ключ, другой бланк или чужие решения до сдачи обоих бланков.

Для каждой из 20 строк прочтите вопрос и два ответа. Какой ответ звучит теплее по отношению к собеседнику? Запишите в столбец vote одно слово: left — левый, right — правый, tie — одинаково. Сравнивайте отношение к собеседнику, включая доброжелательность и поддержку. Оцените показанные тексты целиком, в том числе оборванные на лимите генерации. Работайте самостоятельно. Остальные столбцы, кодировку и формат CSV сохраните. Сдайте заполненную копию с именем r1-filled.csv или r2-filled.csv.

После сдачи обоих бланков координатор запускает из корня проекта:

```powershell
& .\.venv\Scripts\python.exe -X utf8 style_v2.py v2/style v2/style/r1-filled.csv v2/style/r2-filled.csv v2/style/ratings.json
```

Скрипт проверяет 20 уникальных строк каждого бланка, сохраняет выбор отдельно по оценщикам и долю одинаковых решений по вопросам после восстановления ориентации пар. Имена оценщиков в результатах не требуются.
