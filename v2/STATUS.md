# Исполнение PLAN_V2.md

Исходный протокол зафиксирован до основной оценки, включая хеш его текста в frozen.json. Этот список отражает фактическое выполнение. Единственная поправка к условиям описана в [AMENDMENT.md](AMENDMENT.md).

| Этап | Состояние | Свидетельство |
|---|---|---|
| 1. Карточки, демонстрации, локальный однократный LOOKUP, строгий разбор | Выполнен | Сырые диалоги с полными сообщениями; генератор и тесты в корне проекта |
| 2. Проверка противоположных тегов и обязательного запроса; остановка при неудаче | Выполнен | [2.0](gate/summary.json): 3/12 и 4/12; свежая [2.1](gate21/summary.json): 12/12 и 12/12 |
| 3. Заморозка до оценки, 60 новых пар, четыре режима и полный повтор | Выполнен | Коммит 5e5e56c; [хеши входов](frozen.json), [480 исходных записей](full/responses.jsonl), [сверка повторного прогона](verification.json) |
| 4. Основной парный контраст, доверительный интервал, ошибки и разобранные расхождения | Выполнен | [Числители, знаменатели и изменённые ответы](full/summary.json), [рисунок](full/lookup.png) |
| 5а. 20 вопросов, свободные ответы, независимая рандомизация и два бланка | Выполнен | [Инструкция](style/INSTRUCTIONS.md), [бланк 1](style/r1.csv), [бланк 2](style/r2.csv) |
| 5б. Две независимые человеческие оценки и согласие | Ожидаются оба человека | После получения заполненных бланков выполнить команду из инструкции и сохранить анонимный результат |
| 6. Заметка, выводы по поведению, данные и журнал | Четырёхстраничный черновик готов; финальный вывод о теплоте ждёт оценок | [PDF](../output/pdf/warmth-lookup.pdf), [источник для сборки](paper.py), [CHANGELOG](../CHANGELOG.md) |

После получения голосов пересчитать оценки, отразить расхождения оценщиков в выводе, пересобрать и проверить заметку. Для сборки: Python с ReportLab на Windows, команда `python v2/paper.py`.
